# Optimized media (derivatives)

Additive WebP derivatives generated by `npm run optimize:images`.

- Originals under `public/media/` are **never** overwritten or deleted.
- Paths mirror the original site path after `/media/`:
  `/media/projects/2568/arabica-coffee/cover.jpg`
  → `/media/optimized/projects/2568/arabica-coffee/cover.webp`
- Phase A only converts the subset in `scripts/image-pilot.json`.
