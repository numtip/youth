# Handoff — 2026-08-14

Delivery strategy changed from **Docker-first** to **GitHub Pages-first preview
gate**, following the GreenOffice2026 approach:

```
Local validation → GitHub Actions quality gates → GitHub Pages preview → Live acceptance
```

Docker/Nginx/site-platform files are kept but are now a **deferred pre-staging/VPS
gate**, not a current blocker. Docker Desktop is **not required** for the current
work.

## Completed work

- **Base-path compatibility** — the site now builds for both the local root
  (`base: '/'`) and GitHub Pages subpath (`base: '/youth/'`) from the same source.
  - New `src/lib/site.ts` (`withBase`/`stripBase` helpers driven by
    `import.meta.env.BASE_URL`); no hard-coded `/youth/` anywhere in source.
  - `localeHref`/`getLocalizedPathname` (`src/i18n/index.ts`) are now base-aware,
    so navigation, breadcrumbs, cards, search, and the language switcher all work
    on a subpath.
  - `MediaFigure` prefixes `/media/` asset URLs with the base.
  - `BaseLayout` emits a base-aware `<link rel="canonical">` (when `SITE_URL` is
    set).
  - `astro.config.mjs` reads `SITE_BASE`/`SITE_URL` from the environment
    (defaults to `/` so local dev is unchanged).
  - `scripts/smoke-test.mjs` now accepts `SITE_BASE` and asserts internal links
    carry the base path.
- **GitHub Actions** — new `.github/workflows/deploy.yml` with quality gates
  (`npm ci` → `validate` → `check` → `build` → `test:smoke`) plus Pages artifact
  upload and deploy via the official Actions. Least-privilege permissions
  (`contents: read`, `pages: write`, `id-token: write`), a serialized `pages`
  concurrency group, and deploy only on `main` (PRs run gates only).

## Environment strategy

- `SITE_BASE` — Astro `base` (e.g. `/youth/`). Unset → `/` (local root).
- `SITE_URL` — absolute origin for canonical URLs (e.g.
  `https://numtip.github.io`). Unset → no canonical tag emitted.
