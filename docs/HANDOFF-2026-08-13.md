## Architecture

- **Astro static site**: builds to `dist/`; no PHP, no public database, no
  server-side state.
- **Routing**: Thai is default and unprefixed (`/`, `/activities/...`); English
  uses the `/en/` prefix (`/en/`, `/en/activities/...`).
- **Repository content model**: content lives in `src/content/projects/**` and
  `src/content/activities/**` as Markdown + YAML frontmatter, validated by
  `scripts/validate-content.mjs`. `src/data/` holds `projects.json` and
  `legacy-redirects.json`.
- **Validation/media allowlist**: `scripts/validate-media.mjs` fails on any
  missing `/media/` file unless it is listed in `scripts/media-allowlist.json`
  (temporary, until real media is migrated).
- **Local Nginx/Docker target**: `site-platform` Compose stack — a shared gateway
  (binds `127.0.0.1:8080`) proxying `Host: youth.localhost` to `youth-site`
  (no host port). Unknown hosts return 404.
